# 填色图层（智能填色）使用指南

填色图层是从 Krita 移植的「智能填色蒙版」：你在各封闭区域里**点几个色点**，引擎以线稿为墙做分水岭扩散，自动把颜色铺满整个区域。线稿不用封闭到像素级（有闭缝参数兜底），色也不用涂满——每个区域点一下即可。

## 建层

1. 先准备线稿：一个**含有画作的位图图层**（普通颜料层）。
2. 时间轴工具栏的「新建图层」下拉 → **新建填色图层**。建层是静默的，不弹命名框。
3. 填色层自动插在线稿**下方**；线稿源由引擎自动就近寻找（当前帧非空的位图层）。

当前层是填色图层时，**工具选项坞**会出现「智能填色」面板。面板上会显示「线稿源：×××」；如果显示红字「未找到线稿层！」，说明没有可用线稿，先去画线稿。

## 单帧填色的操作循环

面板顶部两个开关默认都开：

- **编辑模式（显示并绘制笔画）**：显示你画的色点；
- **显示填色结果**：显示计算出的填色。

核心循环四步：

1. **选色**：从色板选颜色，或在面板「笔画颜色」列表里点一个已有色块（点色块会联动设为当前笔刷色，接着涂就是同一色）。
2. **点色点**：用**铅笔**（推荐）或笔刷，在填色层上、线稿围住的区域里点一下。每个封闭区域点一个颜色点就够——引擎强制「一区一点」，同区域多点只保留覆盖最大的一个。
3. **标背景**：背景（线稿轮廓之外的大区域）不要点彩色——选中该颜色点后按「**透明**」，它的区域保持不填。透明标记就是留白画法；透明标记点在轮廓外/背景区域，封闭区域内部不要标透明。
4. 点「**刷新**」：重算当前帧并显示结果。

填色是**纯手动**模型（忠实 Krita 语义）：每次改动后都要点「刷新」才重算；「**更新全部**」一次重算整层所有帧。「**删除**」按钮删除当前帧上所选颜色的全部笔画（点错色用它）；橡皮也可以直接擦色点。

## 参数

改参数即整层失效重算：

| 参数 | 默认 | 作用 |
|---|---|---|
| 边缘检测（软铅笔线） | 关 | 线稿是软笔/浅色时才开，把半透明线也当墙 |
| 检测尺寸 | 4 | 边缘检测的搜索范围 |
| 闭缝半径 | 0 | 线稿有细缝/缺口时加大，防止颜色渗漏 |
| 清理强度 | 0.7 | 清除贴边漏填的杂色碎块 |

## 跨帧传播（锚点工作流）

不用逐帧点色。推荐流程：

1. 在**开头/中间/结尾**各挑几帧，手动涂好色点——这些帧就是**锚点**。
2. 点面板里的「**跨帧传播填色**」。引擎把线稿切成区域、按区域对应颜色，自动给其余全部帧铺标准色点并逐帧计算；缺帧自动补建，全程可撤销，进度框可取消。
3. 看传播完成后的**锚点校验报告**：每对锚点显示「帧A→帧B 吻合 正X%/反Y%」。70% 以上属正常；出现「对应不稳对（建议在两锚点之间补涂一个锚点后重传）」时，在问题区间中部补涂一帧色点，再传播一次即可。

两条使用纪律与成本预期：

- **所有锚点帧必须从色板取同一套颜色代码**（红就是同一个红）。锚点间换了色码，校验必然报「未预测到/多预测」。
- 传播约 2~3 秒/帧，十几帧的镜头全程 15~60 秒；中途界面安静不是卡死。

传播过的帧仍可手动修正：修正过的帧自动变为**受保护帧**，不会被下一次传播覆盖，并且会升级为新锚点参与校验。

## 收尾

- **转换成颜料图层**（图层行右键）：把着色结果烘焙成普通位图层，脱离动态计算。转换本身是单步可撤销的换壳操作，但转换后填色层的传播/撤销语义全部作废。
- 不转换直接**导出**也可以：导出只画填色结果，不画色点。

## 能力边界与实战纪律

- 填色层可用的绘画工具：铅笔、笔刷、钢笔、折线、橡皮、吸管、涂抹；**桶、选择、变形刻意禁用**（色点语义不允许大面积操作）。
- 点色点**首选铅笔**（不透明实心）。软笔半透明叠涂会混出中间色，引擎有归并兜底，但铅笔最干净。
- 所有操作可 Ctrl+Z：色点笔画是独立撤销步，传播按帧回滚。
- 填色结果是层内缓存：换帧、改参数、改线稿都会自动失效，但画面更新以「刷新」按钮为准——这是纯手动模型的设计。
