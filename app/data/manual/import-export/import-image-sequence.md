# 导入图像序列与图像预设集的区别

「文件 → 导入」菜单里有两个容易混淆的入口：**导入图像序列**（Image Sequence...）和**图像预设集**（Image Predefined set...）。两者都把一组图片排进时间轴，但选图方式和落点规则完全不同。

## 导入图像序列

- 在文件对话框里**手动多选**任意图片，对文件名没有任何要求。
- 图片导入到**当前图层**，且当前图层必须是位图层。
- 从**当前帧**开始依次排开；对话框里的数值表示「每 N 帧放一张图」（1～64），可用于一拍二、一拍三式的导入节奏。

## 图像预设集

- 只需选**一张**符合 `前缀+数字` 命名的样例图（例如 `Joe001.png`），导入器自动扫描同一文件夹，找出同前缀、同位数、同扩展名的所有文件，并在预览表格里列出「帧号 ↔ 文件」的对应关系。
- 导入时会**新建一个位图图层**，图层名取自文件前缀（如 `Joe`）。
- 每张图落在**文件名编号所指的帧号**上（`Joe005.png` → 第 5 帧），与当前帧位置无关。
- 每张图是一个自动曝光关键帧，**自动延展到下一个编号**：编号跳号时（`002` 之后是 `005`），第 3、4 帧会继续显示前一张图而不是留空；想要真正的空帧，需要放一张透明 PNG 占位。

## 对比一览

| | 导入图像序列 | 图像预设集 |
|---|---|---|
| 选图方式 | 手动多选任意图片 | 选一张样例，按文件名模式自动扫描 |
| 文件名要求 | 无 | 前缀+数字（如 Joe001.png） |
| 落在哪个图层 | 当前图层（须为位图层） | 新建位图图层（名为前缀） |
| 落在哪一帧 | 从当前帧依次排开 | 文件名里的编号 |
| 曝光时长 | 每张按「每 N 帧一张」节奏 | 自动 hold 到下一个编号 |
| 预览 | 无 | 有（帧号 ↔ 文件表格） |

## 和 OCA 的关系

OCA（Open Cel Animation）是动画软件之间的工程交换格式：一个 JSON 清单加一组图片，除了「图落在哪一帧」，还携带图层树、嵌套组、每帧曝光时长、不透明度、混合模式等完整工程结构。

图像预设集的思路和它同源——都是「一堆图片 + 时间轴位置元数据」，但元数据全部压缩在文件名里，只装得下两个信息（前缀 → 图层名、数字 → 帧号），每次导入也只生成一个扁平的位图图层。它的优势是**零门槛**：3D 渲染输出、ffmpeg 抽帧、其他动画软件导出的编号序列（`frame_0001.png` 这类行业惯例）都能直接对接，不要求对方软件实现任何规范。

## 怎么选

- **导入图像序列**：我来挑一堆图，从当前帧挨个排——适合素材零散、顺序自己定的情况。
- **图像预设集**：指一张样例，按文件名编号对号入座到新图层——适合从其他软件导出的、编号里自带节奏和跳号的成品序列。
- **OCA**：双方软件都支持该规范时的完整工程往返（本软件支持 OCA 导出）。
