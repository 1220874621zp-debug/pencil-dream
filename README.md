# Pencil Dream

**Pencil Dream** 是基于开源动画软件 [Pencil2D](https://github.com/pencil2d/pencil) 的深度改造版本：面向传统手绘动画的**纯位图工作流**，时间轴按 **TVPaint** 的交互习惯全面重塑，界面采用 **Procreate Dreams** 风格的深色主题，并移植了 **Krita** 的智能填色与油漆桶引擎。

## 时间轴（TVPaint 风格）

- **曝光块模型**：每个关键帧渲染为一张宽卡片（绘图纸），自动带内容裁剪缩略图（白色缩略图底框）、绘图纸序号（1、2、3…自然数，非时间帧号）
- **块缘拉伸（Trim）**：鼠标悬停块右缘/两块接缝出现 ↔ 光标，按住拖动实时预览调整曝光；中间块为**双向 ripple**（后续块整体跟随让位），**末尾块拖长逐帧生成空白关键帧**、拖短删除实体帧
- **一拍 N（×1~×4）**：停车法四阶段重排，绝不删帧；选中帧版带 TVP 碰撞推挤（区间内未选中帧按原间距推到尾部）；与 trim 共用同一套曝光语义，单步撤销
- **"+" 把手拖拽建帧**：末块右上角拖出即可批量创建帧，带 "+Nf" 预览，单步撤销
- **块拖拽**：层内移动、跨层搬运（同类型层）、Ctrl 整层平移、框选/Ctrl/Shift/Alt 多选
- **空隙自动吸收**：删帧、移动块、曝光缩短时前一个块自动延长补位（TVP 语义），其余场景保留空隙兼容
- **循环克隆**：选中帧（或整层）按原间隔重复 N 次（1-99），单步撤销
- **图层打组**：连续组模型 + 组头行，拖拽多图层到落点成组（落点高亮反馈）、Shift 多选成组；组可折叠（折叠行显示色条，选中层显示强调红框，折叠时默认选中组内最上层）；零侵入扁平序设计
- **图层循环模式**（TVP 式 循环/往复，非复制帧）：图层行角标标记，画布预览实时生效
- **参考视频层**：链接式导入，friction 式按需解码管线（跟随时间轴播放 + 音频输出，逐帧精准 seek）；行内声音开关按钮，非位图层右键菜单可删除图层；仅 ffmpeg 无 ffprobe 环境自动兜底解析时长
- **相机层**：friction 式关键帧红点 + 连线取代旧单格帧块，圆点可自由拖动改位、避让轨道图标
- **透明网格开关**：循环按钮旁一键切换白色纸面 / 透明棋盘格（偏好持久化）
- **视频层行内属性栏**：图层行尾三角展开 friction 式面板（缩放滑杆 + AE 式可拖动数值，横拖 Shift 加速 / 双击精确输入），即时生效
- **声音层**：新建/导入自动建层直进音频选择，时间轴显示波形（深灰胶囊 + 白色细柱 + 音频名）
- **性能**：绘制视口裁剪、行高前缀和、图纸号单趟构建、图层图标栅格化缓存、缩略图 qint64 键 LRU 驱逐、帧选择算法去平方（范围选择按块跳跃）
- **选中态**：仅边框高亮（内容原样透出），拖动时半透明幽灵预览
- **指针跟随**：点击/选中块，播放头立即跳到该位置
- **图层标签色**：点击图层行左缘循环 8 色，轨道全强度着色
- 其他：Alt+滚轮缩放帧宽（默认 120，锚定视口中心）、滚轮调行高、标尺每 5 帧编号、缩略图异步分批生成、智能填色层待更新标记

## 智能填色（Colorize Mask，Krita 移植）

- **算法**：Krita Colorize Mask 分水岭算法全量移植（隔间泛洪 + 线稿间距场）
- **填色图层**（LayerColorize / ColorizeImage）：独立图层类型，画布直描彩色色块，出图只保留填色
- **后台计算**：异步引擎 + 线稿/色块失效联动，时间轴标记待更新，手动刷新出图（对齐 Krita 原生操作）
- **颜色列表**：自动收集色块颜色，透明标记一键切换；**编辑模式**临时显示原始色块
- **选项面板**：当前层为填色图层时显示于工具选项坞（滤波参数滑杆 + 输入框组合行）
- **线稿源**：自动取上方最近位图层，双向就近解析当前帧非空层

## 绘画工具（Krita 对齐）

- **油漆桶全量移植**：封闭间隙距离场（允许溢出控制）+ 扫描线双通道引擎 + 灰度掩码管线；有选区时洪水扫描域硬裁到选区包络（空画布提速一个数量级）；从未绘制的空白关键帧点击即自动实体化（原版静默无填充）
- **选区/变换工具组**：PS 式长按弹出变体菜单（矩形选择+套索 / 移动+变形），短按激活当前变体，按钮右下角小三角角标
- **对位中割工具**：拖拽红/蓝幽灵对位中割，支持平移 + 绕内容中心旋转 + 等比缩放（Ctrl/Shift）
- **剪贴蒙版**：对齐 friction 的保持透明度语义（蒙版层以下方非蒙版层为界，边缘无欠覆盖）
- **穿透模式**：主工具栏一键开关，画布叠加显示当前位图层全部关键帧幽灵，移动工具直接拖动/缩放任意帧图像（含撤销）——修整旧帧姿势专用
- 画布光标专项修复：Windows 光标缓存陈旧、数位板笔悬停不显工具光标等问题逐项根治

## 撤销系统重构

- 强制启用新撤销系统（原版默认关闭时所有撤销记录均为空操作）
- 新增 **LayerLayoutCommand 布局事务**：批量操作（一拍N、批量删帧、粘贴帧、跨层移动、图层重排、"+"建帧、循环克隆、口型插入等）恢复完整关键帧布局（位置/曝光长度/增删帧），单步撤销、无需复制像素
- 像素类操作（粘贴、清空、删选区、导入、翻转）全部补齐撤销记录
- 修复复制帧按钮卡死（找空位误用覆盖语义致无限循环）等历史隐患

## 图层面板（TVP 风格）

- 行内**不透明度滑条**（按住实时拖动，画布与导出同步生效、随工程持久化）
- 行内**锁定开关**：绘画、帧操作、trim、拖拽全部强制拦截
- 全局"可见/锁定"一键切换（全开→全关）
- 拖拽重排为插入语义 + 可撤销；**复制清空**：在原图层上方生成同结构空白帧图层（清稿/描线用）

## 播放与时间控制

- 播放按钮组居中于时间轴工具栏；帧数/倍率输入框贴右边缘（框内数字右对齐）
- 回放范围、入出点、声音开关、擦洗出声、时间码挂到主窗口状态栏右端
- 循环图标采用 Friction 风格；实测帧率显示（低于目标变红）
- 快捷键调整：添加帧=C、后一/前一关键帧=→/←（符合方向直觉）

## 工具集（时间轴"工具"菜单 / 图层菜单）

- **口型同步切换器**：图层命名 A/E/I/O/U/N/MBP/FV/L/WQ 自动识别，点击在"口型"层当前帧插入对应口型
- **调色板提取**：从图片量化主色（5bit 分箱+众数色），生成色块图层 + 写入色彩面板色卡 + 复制色值
- **对位中割参考**：前后关键帧生成红/绿着色参考层，内容中心自动对齐中点
- **视频抽帧中割**：ffmpeg 抽帧预览（LRU 缓存/播放/滑动），批量导入为时间轴图层
- **OCA 导出**：主工具栏 OCA 按钮 + 设置弹窗，按 OCA 格式规范独立实现；层级结构对齐参考实现（每层包折叠组，OpenToonz/friction 可直接导入）

## MCP 自动化（AI 工具接口）

内置 MCP 服务器，供 AI 助手/外部工具驱动创作：

- **绘制原语**：draw_stroke / fill_region / clear_frame
- **智能填色链**：set_colorize_options / request_colorize_update（种子落笔 + 后台计算受控等待 + 结果图回传）
- **自动画中割**：generate_inbetweens（chamfer 距离场插值，等值带抗锯齿 + 连通域去噪，事务单步撤销，首帧预览回传）
- **导出**：export_movie（ffmpeg 预检）
- **原生能力**：apply_hold_length（一拍N）/ bucket_fill（油漆桶）/ duplicate_layer_cleared（复制清空，可指定垫底）/ move_layer

## 摄像机

- 默认分辨率 **1920×1080**（旧工程一次性迁移）
- 相机框：虚线边框 + **90% 动作安全框** + **中心十字**

## 界面与画布

- Procreate Dreams 风深色主题（主题系统含 TVP 绿等多个预设）
- 移除全部矢量功能，纯位图工作流；有限画布（相机框即工作区）
- 洋葱皮面板改造：参数滑杆化 + 灯泡总开关合并前后帧显示；前后帧数允许 0（=关闭该方向幽灵）
- **调色板改造**：大色块扁平拼接零间隙（放大 150%），色块左下角显示名称（深浅自动反色），右键重命名/按色相排序；多色卡下拉切换 + 新建（工程内存储）；色轮面板右下角常驻当前颜色色块
- **画布时间码**：左下角固定显示 HH:MM:SS（帧号按 fps 换算），跨平台等宽字体、无斜杠零
- **启动工程管理面板**：最近工程卡片（16:9 缩略图/名称/日期），点击打开、移入回收站删除、新建与浏览入口（工程缩略图端到端缓存生成）
- 主工具栏新增**导入参考视频**与**导出电影**按钮
- **拖动性能**：不透明度/属性滑杆照 Krita LayerBox 防抖（行矩形局部重绘 + 80ms 停顿落板），层显示参数走单侧缓存失效——高频拖动不再全量重画
- 导出体验：ffmpeg 缺失时给出下载提示，首选项可配置 ffmpeg 路径
- 启动默认加载最近一次打开的工程（无则回退空白/预设）；首选项页图标换用 Krita 设置图标集
- 高 DPI 文字/缓存修复；中键缩放画布；帮助菜单精简（无外链）
- 文件对话框自带缩略图

## 构建

Windows / Qt 6.8 / MSVC / Ninja：

```bash
cmake -S pencil -B build -G Ninja -DCMAKE_PREFIX_PATH=<Qt路径> -DCMAKE_BUILD_TYPE=Release
ninja
```

或直接使用 `build-qt6.bat`（自动配置 vcvars + Qt 路径）。测试基线：**6615 断言 / 116 用例**全绿（含填色引擎/渲染管线/撤销事务/打组/中割算法回归）。

**分发自包含**：windeployqt 挂为构建后步骤（构建目录即完整可分发包），VC++ 运行库（msvcp140/vcruntime140 系列）随构建自动打包到 exe 旁——干净系统免装 redist 直接运行。

## CI / 发布

- **持续集成**（`.github/workflows/development.yml`）：每次推送自动在 Windows + Linux 双平台编译、跑全部测试、打包产物
- **自动发布**（`release.yml`）：推送 `v*` 标签自动构建并发布 Release，附带 **InnoSetup 中文安装包**（含运行所需依赖）
